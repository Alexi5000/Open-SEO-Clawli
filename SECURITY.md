# Security reporting

This policy covers the code maintained in `Alexi5000/Open-SEO-Clawli`. Upstream software and independently hosted services have their own reporting policies.

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/Alexi5000/Open-SEO-Clawli/security/advisories/new). Do not disclose unresolved exploit details in a public issue.

Include the affected commit or version, deployment configuration, reproduction steps, expected and actual behavior, and potential impact. Remove API keys, access tokens, personal information, and customer data from examples and logs. Use synthetic data where possible.

The maintainers will review reports privately and coordinate any fix and disclosure through the advisory thread. This policy does not promise a response deadline or a supported-version window.
